# بكام؟ — قارن الأسعار في مصر

**الموقع:** https://bkam-eg.github.io

موقع بيقارن سعر نفس المنتج في أشهر المتاجر المصرية (نون، أمازون مصر، B.TECH، 2B، كارفور، دريم 2000، الشيخ، ميامي سنتر، XPRS، تريدلاين، Compumarts، فودافون، راية شوب، رنين، زهران، الغزاوي، كيمو ستور، الفرنسية، موبايل مصر، حالا) ويقولك فين الأرخص.
كل حاجة أوتوماتيك: الأسعار بتتحدث كل 6 ساعات من غير أي تدخل، والموقع شغال على GitHub Pages ببلاش.

---

## الأقسام

موبايلات · تابلت · لابتوب · تلفزيونات · شاشات كمبيوتر · كمبيوتر وإكسسوارات · بلايستيشن · سماعات · ساعات ذكية · إكسسوارات موبايل · أجهزة منزلية · أجهزة مطبخ

## إزاي بيشتغل

```
كل 6 ساعات (GitHub Actions: تحديث الأسعار)
  1. update_prices.py   يدوّر في نون على كل سطر في browse.csv ← منتجات نون هي "المرجع"
                        + أول 3 منتجات من B.TECH (موجودة في محلات كتير فبتتقارن أكتر)
                        وكل منتج مرجعي يدوّر عليه بالاسم في باقي المتاجر
                        (لو نون قافل، المرجع بيبقى نتايج كل المتاجر التانية مع بعض)
     + اللينكات المحفوظة في links.json (متاجر من غير بحث: فودافون، راية، رنين، زهران، الغزاوي، كيمو ستور، الفرنسية، موبايل مصر، حالا؛ وكمان B.TECH و2B وXPRS لما البحث ميلاقيش)
  2. fetch_specs.py     يجيب مواصفات المنتجات الجديدة من B.TECH / 2B / كارفور / Compumarts
  3. build_pages.py     يبني صفحة لكل منتج وصفحة لكل قسم + sitemap.xml
  4. حفظ ونشر           commit + push، وGitHub Pages ينشر الموقع
  5. indexnow.py        يبلّغ Bing وYandex بالصفحات اللي أسعارها اتغيرت بس
```

### المطابقة (إزاي بنعرف إن ده نفس المنتج)

- **نفس كود الموديل** (زي `LS27D302GAUXEN`) = نفس المنتج، حتى لو كل متجر كاتب الاسم بشكل مختلف.
- **كودين مختلفين** (زي `MRA55R85` و`55S85HA`) = منتجين مختلفين، حتى لو الاسم شبه بعض.
- الوحدات بتتوحد قبل المقارنة: `100 Hertz` = `100Hz`، `27"` = `27 inch`، `5 Millisecond` = `5ms`، `6.2 Liter` = `6.2L`.
- أي اختلاف في المساحة، اللون، Pro/Max/Ultra، سلكي/لاسلكي، أو نوع الشاشة (OLED/QLED/Micro RGB) = منتجات مختلفة.
- الإكسسوارات (جراب، اسكرينة…) عمرها ما تتقارن بالجهاز نفسه.
- السعر لازم يكون قريب من باقي الأسعار (من 0.6 لـ 1.6 من المتوسط)، وكل منتج في متجر يتربط بمنتج واحد بس.

## تزود قسم أو منتج جديد

زوّد سطر في `browse.csv`:

```csv
search,category,pages,limit,filter,fallback,stores
Samsung Galaxy S26,موبايلات,1,8,yes,,
Philips air fryer,أجهزة مطبخ,1,6,yes,,noon|amazon|btech|2b|carrefour
```

| العمود | معناه |
|---|---|
| `search` | كلمة البحث (إنجليزي، ماركة + موديل بيشتغل أحسن) |
| `category` | اسم القسم بالعربي (قسم جديد بيظهر في الموقع لوحده) |
| `pages` | كام صفحة من نتايج نون |
| `limit` | أقصى عدد منتجات من السطر ده |
| `filter` | `yes` = شيل النتايج اللي ملهاش علاقة بكلمة البحث |
| `fallback` | (اختياري) كلمات بديلة مفصولة بـ `\|` لو نون قافل |
| `stores` | (اختياري) المتاجر اللي بتبيع القسم ده بس، مفصولة بـ `\|` — بيوفّر وقت |

التحديث الجاي هيجيب المنتجات ويبني صفحاتها أوتوماتيك. لو قسم جديد، ضيف اسمه الإنجليزي في `CAT_SLUG` في `build_pages.py` عشان رابطه يبقى مقروء.

## تشغيل يدوي

من تبويب **Actions** في GitHub:

- **تحديث الأسعار** ← Run workflow (بياخد حوالي ساعة ونص)
- **جلب كل المواصفات** ← يجيب مواصفات كل المنتجات الناقصة مرة واحدة
- **دوّر على المنتجات في متاجر تانية** ← يدوّر في خرايط المواقع (بيشتغل لوحده كل يوم)
- **تبليغ Bing بكل الصفحات** ← يبعت كل الصفحات لـ IndexNow

أو محلياً:

```bash
pip install curl_cffi
python scraper/update_prices.py   # الأسعار
python scraper/fetch_specs.py     # المواصفات
python scraper/build_pages.py     # الصفحات و sitemap
```

## قواعد ثابتة

- **مفيش تحايل على الحماية:** المتاجر اللي بتطلب captcha أو Cloudflare أو Vercel checkpoint (جوميا، العربي، سيجما، دبي فون…) مش بنسحب منها.
- **روابط كارفور بتفضل زي ما هي** (بالـ `offer=`)، وروابط الشراء كلها `rel="noopener sponsored"`.
- لو متجر وقف أو منتج اختفى من النتايج، المنتج بيفضل بآخر سعر معروف وعليه علامة "آخر سعر معروف" لحد 14 يوم، عشان صفحته متبقاش 404 في جوجل.
- التحديث ليه 95 دقيقة بالكتير؛ اللي ميلحقش يفضل بأسعاره القديمة لحد التحديث الجاي.

## العمولات

الموقع ممكن ياخد عمولة من بعض المتاجر (affiliate) من غير ما السعر يزيد على المشتري.
لتفعيل العمولة لمتجر: سجّل في برنامج الـ affiliate بتاعه، وبعدين خلّي `"affiliate": True` للمتجر ده في `STORES` في `update_prices.py` وزوّد كود العمولة في الروابط.
